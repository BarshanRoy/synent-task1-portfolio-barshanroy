# Barshan Roy - Personal Portfolio

A responsive personal portfolio website created as **Task 1** for the **Synent Technologies Web Development Internship Program**.

## About the Project

This single-page portfolio presents my profile, technical skills, academic background, projects, and contact information in a clean and responsive layout.

## Features

- Responsive single-page design
- Hero section with profile image
- About Me section
- Technical skills section
- Projects section
- Education section
- Contact section
- GitHub and LinkedIn integration
- Smooth navigation
- Responsive layout for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## Projects Highlighted

### Portable Electrochemical Measurement & Data Acquisition System
Designed a portable electrochemical measurement system using Raspberry Pi for cyclic voltammetry, real-time data acquisition, and electrochemical analysis.

### Java Minesweeper Game
A Java-based Minesweeper game using game logic and object-oriented programming concepts.

### Currency Converter
A frontend web application that converts currencies in real time using exchange-rate API data.

### Smart Candle
An Arduino-based smart lighting project using an LDR sensor and LEDs to respond automatically to ambient light conditions.

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` directly in a browser, or run it using the VS Code Live Server extension.
