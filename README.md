# Barshan Roy - Personal Portfolio

A modern and responsive personal portfolio website developed as **Task 1** for the **Synent Technologies Web Development Internship Program**.

The portfolio showcases my technical skills, academic background, software and electronics projects, and contact information through a clean single-page interface.

## About the Project

This project was developed to create a professional personal portfolio using HTML and CSS.

The website introduces my background as an Electronics and Communication Engineering graduate with an interest in software development, programming, embedded systems, and practical technology solutions.

The portfolio is designed to work across desktop, tablet, and mobile devices while maintaining a consistent and user-friendly interface.

## Features

- Responsive single-page portfolio design
- Professional hero section with profile image
- About Me section
- Technical skills showcase
- Project portfolio cards
- Education timeline

## Projects Highlighted

### 1. Portable Electrochemical Measurement & Data Acquisition System

Designed a portable electrochemical measurement system using Raspberry Pi for cyclic voltammetry, real-time data acquisition, and electrochemical analysis.

**Technologies:** Raspberry Pi, Python, Electronics, Data Acquisition, Cyclic Voltammetry

### 2. Java Minesweeper Game

Developed a Minesweeper game using Java where players uncover safe cells while identifying hidden mines using numerical clues.

**Technologies:** Java, Object-Oriented Programming, Game Logic

### 3. Currency Converter

Developed a frontend web application that converts amounts between currencies using real-time exchange-rate API data.

**Technologies:** HTML, CSS, JavaScript, API Integration

### 4. Smart Candle

Developed an Arduino-based smart lighting system using an LDR sensor and LEDs. The system detects surrounding light levels and automatically activates the LEDs in dark conditions.

**Technologies:** Arduino, LDR, LEDs, Electronics

## Responsive Design

The portfolio includes responsive layouts optimized for different screen sizes using CSS media queries.

The interface adapts its typography, project cards, education cards, contact section, buttons, images, and spacing for desktop, tablet, mobile, and smaller mobile displays.

## Accessibility Improvements

The website includes several accessibility-focused improvements:

- Visible keyboard focus states for interactive elements
- Reduced-motion support using `prefers-reduced-motion`
- Responsive touch-friendly controls
- Improved text and link overflow handling
- Accessible image alternative text
- Semantic HTML structure

## How to Run Locally

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` directly in a web browser.

Alternatively, use the **Live Server** extension in VS Code to launch the website locally.
